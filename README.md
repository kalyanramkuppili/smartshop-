# smartshop-

AI-powered price comparison app for Indian e-commerce. Compare prices across Amazon, Flipkart, and other stores instantly.

##  Features

AI-powered product search using Groq LLM
Real-time price comparison across multiple stores
Product ratings and reviews summary
Smart category suggestions
Beautiful dark theme UI

##  Supported Stores

- Amazon
- Flipkart
- Croma
- Reliance Digital
- Myntra

## Tech Stack

- Java
- Spring Boot
- React
- Node.js
- REST API
- AI / Machine Learning

## setup

1 Clone the repository:
git clone https://github.com/yourusername/smartCART.git
cd smartCART

2 Install dependencies:
npm install

3 Create your .env file:
cp .env.example .env

4 Add your API keys to .env:
Get Groq API key (FREE): https://console.groq.com/keys
Get SerpAPI key (100 free/month): https://serpapi.com/

5 Start the app:
npm start

## Build APK

eas build -p android --profile preview
