# smartshop-

AI-powered price comparison app for Indian e-commerce. Compare prices across Amazon, Flipkart, and other stores instantly.

## 🚀 Features

-  Search for products across multiple stores
-  Compare prices instantly
-  AI-powered product recommendations
-  Compare product specifications
-  Find the best deals
- 🇮🇳 Designed for Indian e-commerce

##  Supported Stores

- Amazon
- Flipkart
- Croma
- Reliance Digital
- Myntra

##  Tech Stack

- Java
- Spring Boot
- React
- Node.js
- REST API
- AI / Machine Learning

#setup
1 Clone the repository:
git clone https://github.com/yourusername/smartCART.git
cd smartCART

2 Install dependencies:
npm install

3 Create your .env file:
cp .env.example .env

4 Add your API keys to .env:
Get Groq API key (FREE): https://console.groq.com/keys
Get SerpAPI key (100 free/month): https://serpapi.com/

5Start the app:
npm start

## Build APK
eas build -p android --profile preview
